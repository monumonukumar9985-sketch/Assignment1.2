# Assignment 1.2 — Development Environment Setup

1. Installed VS Code and Node.js LTS.
2. Installed Live Server and Prettier extensions.
3. Created the folder `web-development-practice`.
4. Created three files: `index.html`, `style.css`, and `script.js`.

**index.html**
```html
<html>
<head>
    <title>My Website</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Welcome to Web Development</h1>
    <script src="script.js"></script>
</body>
</html>
```

**style.css**
```css
body {
    background-color: lightblue;
    text-align: center;
}
```

**script.js**
```javascript
console.log("Hello World!");
```

5. Ran `index.html` using Live Server.
6. Verified Node.js and npm using:

```bash
node -v
npm -v
```

**Submission:** Screenshots of VS Code, Node.js/npm versions, and the webpage running in the browser.
